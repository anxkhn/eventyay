# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Event attendees discover events, reserve tickets, and follow schedules. Organizers manage events, ticketing, speakers, sessions, and attendees.

## Product Purpose

Eventyay is FOSSASIA's open-source event management platform. The unified codebase supports ticketing, calls for participation, scheduling, video, check-in, and organizer administration.

## Capabilities and Constraints

The existing implementation uses Django and Vue. The requested redesign covers the public and organizer experiences, including appearance controls and a color picker. The hosted design preview uses labeled demonstration data. Connecting the redesign to production services remains a separate integration task.

## Brand Commitments

Preserve the Eventyay name and orange identity. The user requested a modern, minimal design with extensive animation and accessibility.

## Evidence on Hand

README.rst documents supported capabilities. Existing templates under app/eventyay document current workflows. Preview events and transaction values are illustrative, not live inventory.

## Accessibility & Inclusion

Keyboard-accessible controls, visible focus, semantic landmarks, clear input labels, adequate contrast, responsive layouts, and reduced-motion support are required.
